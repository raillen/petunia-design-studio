# 02.8 — Design Persona V1 Feature Gate, Commercial Workflows & Post-V1 Roadmap

# Commercial V1 workflows

Brand/logo: shapes, pen/node, booleans, fill/stroke, typography, export SVG/PDF/PNG.

Social/poster: multi-Surface, raster placement, effects, text, export variants.

Illustration: Pencil/Vector Brush, appearance, masks, assets.

Brochure/light publishing: pages, text frames, styles, margins/columns/bleed, PDF.

Data-driven assets: Data Merge preview/generate/export.

# V1 gate

Each workflow has golden project completed entirely in Petunia, saved/reopened, undo/redo tested and exported.

# V1 required

Core tools, parametric shapes, booleans, typography, Surfaces, styles/assets baseline, professional color, SVG/PDF/raster export.

# Stretch

Shape Builder refinements, advanced variable stroke, richer patterns.

# Post-V1

Mesh gradient, advanced DTP master-page logic, envelope variants, specialty print features, deeper external-format compatibility.

# Rule

Roadmap features cannot distort V1 architecture into dead-end representations.
