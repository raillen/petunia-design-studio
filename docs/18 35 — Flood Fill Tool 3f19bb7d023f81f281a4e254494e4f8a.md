# 18.35 — Flood Fill Tool

# Target

Raster pixels or compatible mask. Selection mask constrains output if active.

# Sampling

Source Current Layer or Composite. Click sample interpreted in source color space/working comparison metric.

# Region

Contiguous on/off. Tolerance metric must be defined—e.g. perceptual/color-distance or channel max—with alpha handling. Anti-alias/edge softness policy explicit.

# Fill source

Solid ColorValue, optional pattern/gradient generator if supported. Blend mode/opacity applied through raster operator.

# Job

Large region traversal native, bounded memory with scanline/queue algorithm and cancellation checks. Preview can indicate region outline before commit when feasible.

# Context

tolerance, contiguous, sample merged, antialias, opacity/blend, fill source.

# Tests

Large uniform image, noisy edge, transparency, selection constraint, composite source, cancellation and color profile.
