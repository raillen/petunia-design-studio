# 32 — UI Component Design System Catalog & State Specifications

# Purpose

Take the visual/control atlas down to reusable Qt component contracts.

# Components

Button, IconButton, ToolButton, ToolGroup, SegmentedControl, CheckBox/Toggle, NumericField, UnitField, SliderField, Combo, SearchField, ColorWell, GradientEditor, Tree/Table/List/Grid rows, PanelTab, Section, Popover, Tooltip, HUD, Notification, Progress, Breadcrumb, Dialog primitives and graph editors.

# Each component

Anatomy, tokens, variants, states, keyboard, focus, mouse/pen behavior, accessibility role/name/value, validation, density, theme, HiDPI and test matrix.

# Rule

Feature UI uses catalog components unless a new interaction genuinely requires a reviewed component.
