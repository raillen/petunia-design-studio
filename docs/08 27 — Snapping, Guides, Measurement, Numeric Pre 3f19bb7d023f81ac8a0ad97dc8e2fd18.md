# 08.27 — Snapping, Guides, Measurement, Numeric Precision & Spatial Feedback

# Snapping UX

Snap should feel magnetic but explain itself. Temporary indicator identifies target type/location; labels show equal spacing/distance when relevant.

# Priority

Active tool can weight nodes > guides > geometry etc. User can enable target categories without tuning obscure numeric thresholds by default.

# Snap manager

Preferences/panel provides master toggle and category checklist, tolerance advanced, angle increments. Current master state visible in status bar.

# Guides

Drag from rulers, numeric create/edit, lock/hide, scoped to document/Surface. Guide color can customize for contrast.

# Measurement

Move/transform displays deltas, width/height/angle. Measure tool offers persistent readout only when user pins/copies, otherwise view-only.

# Numeric fields

Scrub, typed arithmetic, unit suffixes, relative operators if supported. Invalid expression does not mutate. Escape restores previous edit.

# Spatial accessibility

On-canvas visual indicator has status/semantic text counterpart so snapping result is not purely visual.
