# 20.8 — Professional Print Presets, Printer Profiles, Validation Evidence & Scope Boundaries

# PrintPreset

Target standard, output profile/intent, bleed/marks, TAC threshold, black preservation, image resolution thresholds, compression, font policy, spot/overprint policy and preflight severity overrides.

# Sources

Built-in generic presets are conservative and not branded as printer-certified. User/imported printer presets can record provider/name/version/profile fingerprints.

# Validation evidence

Preset can reference validator requirements/test suite. “Certified” label only if external certification process actually exists.

# Scope boundaries

V1 is professional document export/preflight, not imposition/RIP/plate setter. Imposition, trapping, JDF, device-specific screening remain Post-V1/plugin unless promoted.

# Trapping

No hidden automatic trapping. Overprint/manual design tools/prepress service can be future subsystem.

# Archive

ExportReport records preset version/profile hashes so output can be reproduced/audited.

# Tests

Preset migration, missing profile, validation mismatch and export reproducibility.
