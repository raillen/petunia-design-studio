# G058 — PDF/X Export Profiles & External Conformance Validation

# Goal

Ship explicitly validated PDF/X profile(s), chosen by market/technical readiness.

# Depends

G038, G040, G057, 20.4.

# Primary

editor-engineer + release/quality verifier.

# Deliverables

selected PDF/X profile descriptor; output intent; page boxes/marks; transparency policy; font embedding/subsetting; preflight rules; external validator integration/corpus.

# Acceptance

All claimed PDF/X fixtures pass designated independent validator; failures are caught before/after export with structured report.

# Non-goal

Claiming every PDF/X variant if only one is validated.
