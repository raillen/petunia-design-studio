# 08.20 — UX, Usability, Information Architecture, Cognitive Load & User Research

# UX principle

Optimize expert repetition without making first success cryptic. Progressive disclosure: common control in context bar, complete control in Properties/panel, rare advanced control in popover/dialog.

# IA

Global document actions in menus/toolbar; tool-local operations in context; object properties in Properties; collections/resources in dedicated panels; settings never mixed into document properties.

# Discoverability

Every icon-only control has tooltip/accessible name. Grouped tools show marker and remember last tool. Command palette provides alternate discovery.

# Cognitive stability

Panel positions and context control order should not jump unnecessarily. Persona switches update relevant workspace while preserving document mental model.

# Error prevention

Disable invalid actions with reason; preview destructive conversions; target indicators for raster mask/channel; explicit linked vs embedded resources.

# Recovery

Undo first-class, Cancel consistent, autosave/recovery visible when needed, Reset/Revert on edited property groups.

# Research

Maintain task-based studies: create logo, edit photo, brochure layout, batch social exports, data merge. Measure completion, errors, search/undo frequency and perceived confidence.

# Comparison

Affinity reference is used to identify expected professional conventions; tests ask whether Petunia is equal/better for task clarity, not whether layout is visually identical.

# Accessibility as usability

Keyboard, larger hit targets, reduced motion, readable labels and semantic focus are baseline UX, not separate mode.
