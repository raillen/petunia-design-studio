# 11.2 — Brand Personality, Visual Identity Principles & Non-Copying Rules

# Personality

Professional, calm, precise, approachable, creative and technically trustworthy. Avoid playful visual noise that undermines long editing sessions.

# Petunia motif

Botanical naming can influence subtle identity/illustration but must not reduce tools to decorative metaphors or compromise readability.

# Visual

Own neutral palette + controlled accent; original iconography; dense professional layouts; accessible contrast; restrained motion.

# Reference products

Affinity, Krita, Photoshop, Illustrator, Blender and others are workflow prior art. Do not trace/copy proprietary icons, branded colors, screenshots, exact chrome or unique trade dress.

# Voice

UI text concise and helpful, never cute during errors/data-risk. Technical diagnostics precise; onboarding can be warmer.

# Accessibility

Brand styling never overrides focus visibility, contrast, target size, screen reader naming or reduce-motion preference.
