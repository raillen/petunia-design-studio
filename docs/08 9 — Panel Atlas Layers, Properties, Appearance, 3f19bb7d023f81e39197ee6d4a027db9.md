# 08.9 — Panel Atlas: Layers, Properties, Appearance, Color, Assets, History & Photo Panels

# Layers

Virtualized tree. Disclosure, thumbnail, type icon, name, badges, visibility e lock. Drag reorder/nest com insertion preview. Inline rename. Effects/masks nested. Multi-selection first-class.

# Properties

Schema-driven inspector. Mixed values explícitos, reset/revert, validation. Generic property renderer é preferido a painéis hard-coded.

# Appearance

Ordered fills/strokes/effects. Add, duplicate, reorder, toggle, remove. Selected appearance entry dirige tool handles/controls.

# Color

RGB/CMYK/Lab/Gray conforme documento, opacity, fill/stroke target, recent. Document profile visible. Valores são semantic color.

# Swatches

Document/app palettes, globals, spots, gradients. Global swatch references propagam edits.

# Stroke

Width, alignment, cap, join, miter, dash, arrowheads, profile.

# Transform / Align

Numeric X/Y/W/H/rotation/shear/anchor; align key object/selection/Surface e distribute spacing.

# Typography / Paragraph

Font search, family/style/variable axes, size, leading, tracking, kerning, baseline, OpenType; alignment, spacing, indents, tabs, language/hyphenation.

# Assets / Symbols / Styles

Searchable libraries, drag placement, symbol definitions/instances/overrides, object/text styles com preview.

# History

Command transaction list; labels derivadas de Action metadata. Navegar history usa undo/redo semantics, não snapshot arbitrário.

# Navigator

Thumbnail + viewport rectangle + zoom.

# Export

Targets/slices/presets/output status.

# Histogram / Channels / Adjustments

Async histogram; channels/alpha/masks target UI; searchable live adjustments.

# Brushes / Brush Settings

Preset virtualization + detailed dynamics editor.

# Masks / Info

Mask stack/target; cursor coordinates/channels/profile/object metadata.

# Developer-only

Performance, scene cache, Action inspector, semantics tree em dev builds.
