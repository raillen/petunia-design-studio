# 19.09 — Assets / Symbols / Styles Panels Specification

# Assets

Grid/list virtualized, source/category/search/tags/favorites. Drag place and keyboard Place action. Thumbnail async.

# Symbols

Definitions list with instance count, preview, create from selection, edit definition, detach instance and override status.

# Styles

Separate Object/Character/Paragraph views or type filters. Apply, create, update/redefine, duplicate, organize/tag and import/export.

# External libraries

Missing provider/library shows unavailable entry without corrupting document refs.

# Drag/drop

Assets into canvas create PlaceAsset transaction; styles dragged to compatible object applies same Action as click.

# Tests

100k assets, symbol update, detach, style override, missing library and keyboard placement.
