# 19.08 — Align & Distribution Panel

# Identity

PanelId ptnd.panel.align.

# Target reference

Selection bounds, Key Object, First/Last selected, Surface, margins or guide target when applicable.

# Align

Left, horizontal center, right, top, vertical middle, bottom; text-baseline alignment is separate text-aware action.

# Distribution

Centers/edges and equal spacing horizontally/vertically. Numeric gap mode can set exact spacing.

# Key object

UI visibly marks key object; it remains fixed during operation.

# Commands

AlignObjects, DistributeObjects, SetEqualSpacing.

# Accessibility

Buttons have explicit labels/tooltips and command palette alternatives.

# Tests

Rotated bounds, mixed sizes, key object, Surface margins, negative spacing and undo.
