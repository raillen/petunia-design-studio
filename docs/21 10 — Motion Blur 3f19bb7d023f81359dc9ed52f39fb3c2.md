# 21.10 — Motion Blur

# ID

ptnd.effect.motion_blur.

# Parameters

distance/radius in document pixels, angle degrees, edgeMode, quality/sample policy.

# ROI

Expand by projected blur vector extents on each side based on distance/angle.

# Algorithm

Reference samples along linear trajectory with normalized weights. Interactive GPU may use optimized taps; Final meets reference error tolerance.

# Transform

Angle defined in document/world coordinates unless effect transform space explicitly local. Rotating object with live effect behavior documented.

# Alpha

Premultiplied handling.

# UI

Distance, angle field/dial/on-canvas line optional.

# Tests

Impulse line, angles 0/45/90, alpha, transformed object, ROI and GPU parity.
