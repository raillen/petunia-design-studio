# 00.2 — Jobs-to-be-Done, User Segments & Canonical Workflows

# Core segments

Graphic designer/brand designer; illustrator; photographer/retoucher; marketing/content team; independent Linux creative; automation-heavy creator.

# JTBD — brand design

“When I create a visual identity, I need precise vector construction, typography, reusable styles/assets and reliable SVG/PDF/raster delivery without switching apps.”

# JTBD — photo

“When I retouch/composite an image, I need responsive brushes, selections, masks and nondestructive adjustments that preserve quality and remain editable.”

# JTBD — publishing

“When I make a brochure/social campaign, I need multiple Surfaces/pages, linked text, margins/bleed, print preflight and reusable styles without a separate Publisher product.”

# JTBD — batch/data

“When producing many variants, I need data bindings, preview/preflight, deterministic generation and naming so automation does not corrupt templates.”

# JTBD — extension

“When my workflow is specific, I need plugins/MCP that operate the same semantic commands as UI and can be permissioned/audited.”

# Canonical workflow benchmarks

Logo/identity; social poster set; vector illustration; portrait cleanup; product cutout; mixed poster; brochure/light publishing; data-merged 100 outputs; professional PDF handoff; extension/automation demo.

# Research metrics

Task completion; time; undo/error count; command search use; panel hunting; destructive conversion mistakes; target ambiguity; accessibility blockers; perceived confidence.
