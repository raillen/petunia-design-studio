# 20 — Print, Prepress, PDF/X, Separations, Overprint & Professional Output

# Goal

Concentrar requisitos de produção impressa que hoje aparecem dispersos em Color/Export.

# Scope

CMYK/ICC output, spot inks, registration color, overprint/knockout, separations preview, ink coverage/TAC, bleed, trim/media/bleed/art boxes, crop/registration/color bars, PDF/X profiles, font embedding/subsetting, transparency, black preservation and output intents.

# Principle

Prepress semantics are canonical/output semantics, not visual approximations. Screen preview may approximate but output/preflight must retain explicit intent.

# V1 policy

PDF/X claim only after exact target/version, writer capability and external validation fixtures. Before that Petunia may export professional PDF with honest conformance status.

# UI

Preflight/Export/Separations panels expose warnings per object/ink/page and navigate to source.
