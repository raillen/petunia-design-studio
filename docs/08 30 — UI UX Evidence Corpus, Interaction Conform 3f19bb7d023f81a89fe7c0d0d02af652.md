# 08.30 — UI/UX Evidence Corpus, Interaction Conformance & Human-Factors Gauntlet

# Corpus

Maintain canonical small documents/screens for each interaction: empty, logo vector, brochure text, photo retouch, mixed poster, data merge, huge image, missing resource.

# Interaction scripts

Human-readable steps plus semantic automation where possible. Each records initial state, action sequence, expected canonical change, visible feedback and recovery.

# Human-factors gates

Discoverability, accidental destructive action rate, mode awareness, target awareness, modifier clarity, undo confidence, error recovery and keyboard completion.

# Reference comparison

Affinity/other professional tools can establish baseline task vocabulary and expected features. Petunia-specific improvements are documented.

# Retained evidence

Screenshots/videos are secondary to semantic snapshots; store build ID, OS, theme, DPI and fixture.

# No screenshot-only acceptance

A visually matching UI with wrong Action/Command semantics fails. A semantically correct UI with unusable feedback also fails.
