# 19.13 — Styles Panel

# Identity

PanelId ptnd.panel.styles.

# Types

ObjectStyle, CharacterStyle, ParagraphStyle and future style domains.

# Hierarchy

Style inheritance supported only where domain declares; cycles rejected. Base style and local override count visible.

# Actions

Create from selection, Apply, Redefine, Duplicate, Rename, Delete/Reassign, Clear Overrides, Detach formatting.

# Preview

Async object/text preview from canonical style.

# Libraries

Document/user/provider scopes, search/tags/categories.

# Commands

CreateStyle, ApplyStyle, UpdateStyle, ReparentStyle, DeleteStyleWithPolicy.

# Accessibility

Style name/type/base/override state exposed.

# Tests

Inheritance, override cascade, delete referenced, text/object styles and migration.
