# 08.26 — Typography, Text Editing, Layout & Precision UX Contract

# Text modes

Object selection vs caret editing is visually distinct but transitions are simple: Text Tool click enters editing; Esc returns object mode.

# Font picker

Search family/style, favorites/recent, variable font badge/axes, missing font state. Preview does not block typing.

# Context vs panels

Context: font, style, size, basic alignment/color. Typography: OpenType/axes/tracking/kerning/baseline. Paragraph: paragraph geometry/hyphenation/tabs.

# Frame text

Overflow indicator is actionable; ports show link state; text flow direction clear. Dragging frame resizes container, not font size by default.

# Precision

All typographic numeric controls accept units/expressions where meaningful and show mixed values for selection.

# Layout overlays

Baseline grid, columns, margins, frame bounds and text wrap indicators are unobtrusive and toggleable.

# Accessibility

Caret/selection semantics exposed to platform; IME candidate location correct; keyboard shortcuts follow platform editing conventions.
