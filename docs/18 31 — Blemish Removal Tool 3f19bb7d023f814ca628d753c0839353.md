# 18.31 — Blemish Removal Tool

# Purpose

Fast spot/small-region healing optimized for blemishes.

# Interaction

Click creates circular target; short drag creates elliptical/brush target. Tool suggests source automatically or exposes source patch handle depending engine/mode.

# Parameters

size, hardness/feather, opacity/strength, source auto/manual, sample scope.

# Preview

Destination and optional source patch outlines. Drag source handle adjusts sample after placement before commit if workflow uses explicit patch objects/staged edit.

# Engine

Uses healing/inpainting service with small ROI fast path.

# Commit

One BlemishRemoval command/raster delta per click/drag. Repeated spots remain separate undo entries unless explicit session coalescing.

# Tests

Skin-like texture fixture, edge boundaries, auto-source failure, manual source, high bit depth and undo.
