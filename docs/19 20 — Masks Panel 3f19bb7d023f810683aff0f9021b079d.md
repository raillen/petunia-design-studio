# 19.20 — Masks Panel

# Identity

PanelId ptnd.panel.masks.

# Purpose

Focused management of masks attached to selected object/group/effect when Layers tree alone becomes dense.

# Model

Ordered masks with type Pixel|Vector|Luminosity/derived, enabled, linked transform, invert, thumbnail and target.

# Actions

Add Pixel Mask, Add Vector Mask, Mask from Selection, Invert, Enable/Disable, Unlink/Link transform, Delete, Convert/Apply where semantically valid.

# Editing target

Click mask row sets mask target; context/status repeats target. Alt/Option solo mask preview if adopted.

# Combine

If multiple masks supported, combine operation and ordering shown explicitly.

# Accessibility

Mask type/state/target announced; all actions menu/keyboard available.

# Tests

Nested effect masks, pixel/vector, target switch, transform linking, deletion and save.
