# 08.10 — Window & Dialog Atlas

# New Document

Presets, dimensions, units, orientation, DPI, color format/profile, background, margins, bleed, Surface/page mode. Invalid combinations têm explicação.

# Document Setup

Mesmos schemas sobre documento existente. Color/profile conversion com preflight e explicit policy.

# Preferences

Searchable categories: General, UI, Tools, Performance, Color, Files, Shortcuts, Plugins, MCP/Automation, Updates, Accessibility.

# Resource Manager

Linked/embedded images/fonts/data: status, relink, embed/unembed, replace, reveal.

# Missing Fonts

List missing, substitution preview, locate/install/relink, global/selected substitution.

# Plugin Manager

Install/update/enable/disable/uninstall, permissions, runtime/status/logs. Escalation de permission exige consentimento novo.

# MCP Manager

Server/client status, scopes/grants, revoke, audit summary, semantic inspection developer toggle.

# Export / Batch Export / Preflight

Typed settings, output targets, degradation list, progress/cancel/retry.

# Recovery

Candidate explicit-save/recovery times, source, safe preview. Open recovery cria unsaved recovered session.

# About/Diagnostics

Version/build, licenses, renderer backend, system info, diagnostics bundle. Secrets são redacted.

# Progress

Background job UI preferida; modal somente se operação bloqueia o document necessariamente.
