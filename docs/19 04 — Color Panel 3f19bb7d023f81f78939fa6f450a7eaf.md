# 19.04 — Color Panel

# Identity

PanelId ptnd.panel.color.

# Target

Fill, Stroke, Gradient Stop, text color, brush foreground/background or other ColorTarget explicitly displayed.

# Modes

RGB, CMYK, Lab, Gray, Spot/Swatch reference display according target/document support. Wheel/sliders/spectrum are views over semantic ColorValue.

# Controls

Target selector Fill/Stroke; swap; default colors; None where allowed; model/profile label; component sliders/fields; alpha; color picker link; recent colors.

# Editing

Dragging spectrum/sliders stages one transaction. Numeric fields preserve precision and locale. Changing model can Convert or edit representation according explicit command—not reinterpret silently.

# Swatch link

If target uses global/spot swatch, panel indicates link. Editing components can edit global swatch or detach/current object via clear user choice.

# Gamut/proof

Optional warning badges reflect current proof view but do not rewrite color.

# Accessibility

Every visual color control has numeric labels/value and text name/profile semantics.

# Tests

CMYK/Lab/spot, linked swatch, gradient stop, mixed targets, alpha, proof mode, high-precision roundtrip.
