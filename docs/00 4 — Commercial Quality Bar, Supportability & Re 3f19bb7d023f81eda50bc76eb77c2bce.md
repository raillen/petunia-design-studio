# 00.4 — Commercial Quality Bar, Supportability & Release Readiness

# Commercial quality

No known data-loss P0/P1. Save/recovery torture suite passes. Core workflows meet performance/accessibility gates. Format support has evidence. Install/update/uninstall reliable.

# Supportability

Structured diagnostics, BuildId, reproducible artifacts, known-issues list, crash bundles, migration fixtures and safe rollback guidance.

# Product telemetry

No mandatory telemetry for core use. Optional diagnostics/analytics require explicit privacy policy, minimal collection and opt-in/legitimate UX.

# Compatibility

PTND forward/backward behavior documented. Plugin/MCP version windows explicit. External format claims tied matrix.

# Release tiers

Nightly/Developer → Alpha → Beta → Stable. Each has documented guarantees; Alpha may have incomplete fidelity but never intentionally unsafe save behavior.

# Quality debt

A feature can be experimental only if clearly labeled and isolated from canonical data corruption risk.
