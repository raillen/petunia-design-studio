# 00.3 — V1 Scope Matrix, Stretch Goals, Post-V1 & Explicit Non-Goals

# V1 Required

Canonical PTND; Design/Photo Personas; vector shapes/paths/booleans; fills/strokes/gradients; layers/groups/masks; text; Surfaces/layout basics; raster/tile engine; brush/selection/crop/retouch baseline; adjustments/live filters; ICC color; PNG/JPEG/WebP/TIFF/SVG/PDF baseline; docking/workspaces; undo/recovery; plugins/MCP baseline.

# V1 Stretch

Shape Builder polish, richer vector brush, advanced selection refine, more live effects, stronger print/preflight, more importers.

# Post-V1

Mesh gradients, advanced DTP, PSD depth, RAW develop, HDR/panorama/focus merge, advanced ML tools, collaborative/cloud provider, additional CAD/publishing interchange.

# Non-goals

Video/motion timeline, full 3D, DAW/audio, browser-hosted editor, mandatory cloud document model, arbitrary in-process third-party native ABI in V1.

# Scope governance

Every feature request maps to Required/Stretch/Post-V1/Research/Not Planned with authority and rationale. “Affinity-like” never auto-promotes a competitor feature into V1.
