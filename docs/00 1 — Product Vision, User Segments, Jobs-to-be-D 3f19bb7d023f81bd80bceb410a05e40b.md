# 00.1 — Product Vision, User Segments, Jobs-to-be-Done & Competitive Position

# Vision

Petunia Design Studio is a professional local-first creative desktop application combining vector design, raster/photo editing and selected layout/publishing workflows in one document model.

# Primary user segments

- independent designers and illustrators;
- photographers/retouchers;
- marketing/communications teams;
- Linux users underserved by mainstream proprietary tools;
- technical creators who benefit from automation/plugins/MCP;
- small studios needing interoperable open project files.

# Jobs-to-be-done

Create brand/logo assets; prepare social/marketing graphics; retouch/composite photography; create print-ready documents; generate data-driven variants; export production assets; automate repeatable design operations.

# Positioning

Petunia should compete on coherent workflow, openness, Linux support, extensibility, accessibility and inspectable automation—not on copying competitor identity.

# Product constraints

Professional precision and non-destructive editing outrank novelty. Local/offline work must remain first-class. No mandatory cloud/account for core creation. Automation must never become a second-class shadow API.

# Success

A user can complete real paid-work workflows end-to-end without leaving Petunia for basic vector/raster/layout tasks. Commercial readiness is measured by golden workflows, stability, fidelity and supportability, not feature count alone.
