# 18.33 — Smudge Tool

# Purpose

Drag/push local pixel color along stroke.

# State

Stroke maintains pickup/carry buffer initialized from source at beginning and updated with sampled destination according strength/mix.

# Parameters

size, hardness, strength, flow, spacing, finger-paint/start-color option if supported, sample scope.

# Engine

Requires tile halo and sequential dab ordering; parallelism allowed only across independent tile regions without violating carry state.

# Color

Smudge operates in defined working representation; alpha behavior explicit to avoid transparent fringe artifacts.

# Commit

One raster delta stroke.

# Tests

Cross-tile stroke, transparent edge, high-strength, long stroke, transformed layer and deterministic output.
