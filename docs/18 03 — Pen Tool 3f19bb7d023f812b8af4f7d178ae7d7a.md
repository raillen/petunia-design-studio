# 18.03 — Pen Tool

# Identity

ToolId ptnd.tool.pen. Shortcut P.

# State machine

Idle -> StartAnchor -> BuildingPath.

BuildingPath + click = corner node.

BuildingPath + drag = smooth node/handle.

Hover first node + click = close.

Enter = finish open path.

Esc = cancel latest uncommitted stage, then finish/cancel according state.

Modifier during handle drag breaks/constrains handle relation.

# Preview

Rubber-band segment, snap target, closure highlight, handles and angle/length HUD.

# Context

Pen|Smart|Polygon mode; fill/stroke; node default; snapping; continue existing path.

# Existing path

Eligible open endpoint highlights before continuation/join. No silent merge of unrelated contours.

# Command

New path commits one logical CreatePath transaction at finish; continuing path commits EditPath transaction.

# Boundary

Python manages interaction state; C++ performs curve/snap/tangent geometry.

# Accessibility

Numeric coordinate input and status announcements for angle/distance/snap.

# Tests

Open/closed, continuation, click-vs-drag threshold, tangent snap, lost pointer capture, undo.
