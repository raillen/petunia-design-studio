# 02.6 — Precision: Grids, Guides, Snapping, Measurement, Transform & Alignment

# Coordinate systems

Document, Surface-local and object-local coordinates are explicit. UI shows active coordinate reference when numeric fields could be ambiguous.

# Grids

Document rectangular, pixel, baseline and separate perspective subsystem.

# Guides

Create from rulers/numeric commands, lock/hide/color/scope. Snap participation independent from visibility only when policy explicit.

# Smart guides

Centers, edges, equal spacing, baselines and dynamic measurements.

# Transform

Exact X/Y/W/H/rotation/shear/anchor, expression input and unit conversion.

# Align/distribute

Selection/key object/Surface targets. Equal spacing with visual measurements.

# Measure

Distance/angle/deltas, copy values, create guide from measurement as explicit action.

# Precision UX

All pointer-created geometry can be corrected numerically without reconstructing.
