# 19.21 — Info Panel

# Identity

PanelId [ptnd.panel.info](http://ptnd.panel.info).

# Data

Pointer document coordinates; active Surface/local coordinates; sampled canonical/composite/display color values; alpha; object/type/id summary; selection dimensions; optional memory/render debug hidden by dev mode.

# Sampling

Updates throttled to UI rate while pointer moves. It requests sample service asynchronously where GPU readback would stall; previous value can show updating state.

# Units

Coordinates follow chosen unit; color values follow selected model/profile display and clearly name sample mode.

# Interaction

Rows can copy numeric/color values. No document mutation.

# Accessibility

All information textual, grouped and selectable/copyable.

# Tests

Proof/display modes, mixed DPI, raster/vector sample, CMYK/spot source and throttle behavior.
