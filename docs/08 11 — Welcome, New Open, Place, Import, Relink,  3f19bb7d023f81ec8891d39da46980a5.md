# 08.11 — Welcome, New/Open, Place, Import, Relink, Autosave & Recovery UX

# Welcome

Recent files, New, Open, recovery banner, learning/help. Missing recent item oferece Locate/Remove.

# Open

Native picker. Strong sniffing pode contradizer extension com warning. Newer unsupported required capability -> read-only/compatibility/refusal explicável.

# Place

Linked/embedded option. Staged placement cursor; click intrinsic/default size; drag defines size; Esc cancela.

# Import

Interpretation dialog apenas para decisions que afetam fidelity. Successful import gera structured report.

# Relink

Missing ResourceId persiste. Relink individual, same-folder batch ou granted-directory search; filename sozinho não prova identidade.

# Save

Atomic snapshot/save. Dirty clears somente após validated destination commit. Edits após snapshot deixam tab dirty corretamente.

# Save As

Native default .PTND. External format routes Export/Save Copy, não substitui native model silenciosamente.

# Autosave

Recovery journal/checkpoint fora do arquivo principal por default. Falha vira visible attention state; sucesso é quiet.

# Recovery

Nunca sobrescreve original. Discard é explícito.

# External changes

Watcher detecta destination changes; Reload/Save Copy/Overwrite após preservar unsaved edits.
