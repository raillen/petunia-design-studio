# 03.8 — Photo Persona V1 Feature Gate, Commercial Retouch Workflows & Post-V1 Roadmap

# Commercial V1 workflows

Photo correction: crop/straighten, white balance, exposure, curves, HSL, sharpen, export.

Portrait cleanup: selections/masks, heal/blemish/clone, dodge/burn, live adjustments.

Composite poster: raster layers + vector/text + masks/effects.

Product cutout: selection brush/refine, mask, background replacement, export alpha.

Digital painting: brush presets/dynamics, eraser, masks, blend modes.

# V1 required

Tiled raster storage, brush/eraser, core selection tools, masks, crop, clone/heal, basic inpaint or equivalent repair, adjustments, live filters, histogram/channels, color-managed export.

# Stretch

More sophisticated edge refine, advanced denoise, liquify-like warp and specialty retouch.

# Post-V1

Full RAW development pipeline, advanced frequency-separation helpers, HDR merge, panorama, focus stacking, sophisticated ML segmentation/generative tools unless promoted.

# Gate

Each commercial workflow has deterministic fixture/project, save/reopen, undo, memory/perf evidence and final export comparison.
