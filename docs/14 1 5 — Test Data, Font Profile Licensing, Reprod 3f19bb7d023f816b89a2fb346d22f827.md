# 14.1.5 — Test Data, Font/Profile Licensing, Reproducibility & Fixture Provenance

# Provenance

Every bundled test font/image/profile/document has license/source and redistribution permission.

# Fonts

Use open deterministic fonts covering Latin, Arabic, Hebrew, Indic, CJK subsets and emoji/color where licensing permits. Font versions pinned.

# ICC

Known open/reference profiles stored with hash/version/source. Malformed profiles generated in fuzz corpus, not copied from private customer files.

# Images

Synthetic/reference test charts preferred for math/color; real photographic fixtures licensed and documented.

# Privacy

Never turn user/customer documents into repository fixtures without explicit authorization/sanitization.

# Reproducibility

Fixtures immutable by hash except reviewed update; external downloads not required during ordinary CI.
