# 02.4 — Vector Composition: Booleans, Shape Builder, Compound Paths, Symbols & Styles

# Boolean

Live and baked Add/Subtract/Intersect/XOR/Divide. Live preserves operands for later edit.

# Shape Builder

Interactive region highlight/add/subtract over selected shapes. Native planar geometry.

# Compound paths

Contour grouping/fill-rule behavior distinct from boolean merge.

# Symbols

Definition + instances + controlled overrides. Updates propagate; detach converts local editable copy.

# Object styles

Reusable appearance/property bundle; linked styles expose local override indication and clear/redefine operations.

# Text styles

Character/Paragraph style system integrates with typography subsystem and Data Merge.

# Consistency

Live constructs display meaningful nesting/badges in Layers and Properties.

# Batch

Actions work on multi-selection through capability filters and report incompatible objects rather than silently skipping when risky.
