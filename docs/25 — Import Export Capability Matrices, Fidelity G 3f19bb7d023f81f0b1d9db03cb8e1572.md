# 25 — Import/Export Capability Matrices, Fidelity Grades & Format Roadmap

# Purpose

Definir suporte por capacidade, direção e fidelidade. “Support X” sem esta matriz é proibido em documentação e marketing.

# Directions

Open/Edit Native, Import, Place/Link, Export, Roundtrip. Cada uma possui status independente.

# Fidelity grades

Exact; EquivalentAppearance; Approximate; Expanded/Outlined; Rasterized; MetadataOnly; Unsupported.

# Capability dimensions

Geometry, text, raster/bit depth, color/ICC/CMYK/spot, masks/clips, effects/blends, pages/artboards, symbols/styles, resources/links, metadata, nondestructive semantics and external extensions.

# Status

V1 Required, V1 Stretch, Post-V1, Research, Not Planned. Claim requires fixture/test evidence.

# Preflight

Export matrix drives degradation plan before encoding. Import report records unsupported/expanded/substituted features.

# Rule

Compatibility is versioned by adapter and target format profile/version.
