# 19.12 — Symbols Panel

# Identity

PanelId ptnd.panel.symbols.

# Model

SymbolDefinition list with thumbnail, name, scope and instance count.

# Actions

Create Symbol, Place Instance, Edit Definition, Detach, Rename, Duplicate, Locate Instances, Delete with detach/replacement policy.

# Overrides

Detail exposes allowed overrides grouped by instance/object/property; modified overrides badged. Reset individual/all.

# Editing

Definition isolation mode has canvas breadcrumb/context. Definition edits invalidate/update all instances.

# Cross-document

Library symbol placement copies definition/resources into document unless future linked-symbol mode explicitly enabled.

# Accessibility

Definition/instance relationships announced; all actions keyboard accessible.

# Tests

Nested symbol policy, overrides, detach, deletion, dependencies and save/reopen.
