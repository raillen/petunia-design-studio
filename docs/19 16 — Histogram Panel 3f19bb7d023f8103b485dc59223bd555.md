# 19.16 — Histogram Panel

# Identity

PanelId ptnd.panel.histogram.

# Scope

Active document composite, selected layer/object rasterization, or selection-constrained analysis.

# Channels

Luminance and native color channels appropriate to document/sample. CMYK/Gray/Lab channel naming follows semantic color model.

# Computation

AnalysisService jobs snapshot source revision and ROI. Bins: 256 baseline for 8-bit display; higher-resolution/float histograms configurable internally. UI may normalize/log-scale display without changing counts.

# Staleness

Panel marks updating subtly. Results tagged revision; stale job discarded. Slider/brush activity coalesces requests.

# Readouts

Count, mean/median optional, clipping percentages, min/max sample, selection pixel count where useful.

# Interaction

Hover bin displays range/count; clipping toggles can enable view overlay if product scope.

# Accessibility

Histogram visual has textual statistics/table alternative.

# Tests

8/16/float, CMYK/Gray, selection scope, stale cancellation and large image performance.
