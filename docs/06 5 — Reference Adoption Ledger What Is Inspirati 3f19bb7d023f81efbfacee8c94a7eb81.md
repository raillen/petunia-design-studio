# 06.5 — Reference Adoption Ledger: What Is Inspiration vs Contract

# Levels

**Observation** — another product/library does something.

**Prior art** — proven approach worth studying.

**Experiment candidate** — approach worth prototyping.

**Petunia contract** — accepted into canonical notebook/ADR.

These levels must never be conflated.

# Affinity

Reference for unified creative workflows, dense professional UI, vector/pixel/layout expectations and export/preflight experience. Not source for code/assets/trade dress.

# Blender

Reference for semantic operators, mature desktop modularity and heterogeneous undo lessons. Petunia avoids broad global context coupling.

# Krita

Reference for raster/brush UX, presets, painting performance patterns and Linux desktop realities. Petunia keeps one coherent Design+Photo product grammar.

# Inkscape

Reference for SVG/vector interoperability and open vector editing; Petunia remains broader than SVG document semantics.

# Scribus

Reference for print/prepress/layout concepts; Petunia V1 deliberately limits deep DTP/imposition scope.

# Skia/Dawn/Qt

Technology candidates/prior art; only ADR + benchmark can make them implementation contract.

# Governance

Every new external inspiration added to architecture must state Adopt/Adapt/Avoid and whether it changes a locked Petunia invariant.
