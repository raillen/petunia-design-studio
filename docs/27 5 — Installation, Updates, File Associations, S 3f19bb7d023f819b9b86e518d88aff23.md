# 27.5 — Installation, Updates, File Associations, Sandboxing & Offline Operation

# Install

Per-platform package contains application, Python runtime, Qt plugins, native libs, shaders/resources, schemas and licenses/SBOM metadata as required.

# Associations

.PTND registered to app with icons/open command. Opening file while app running routes to session coordinator safely.

# Update

Stable/Beta/Nightly channels; signed metadata/artifacts; staged download/install; rollback/cancel; document format compatibility shown before irreversible upgrade where relevant.

# Sandboxing

Platform package sandbox choices must preserve professional file workflows via file grants/portals. Plugin host has stricter isolation than main app.

# Offline

Core editing, save/open/export and local plugins remain usable without account/network. Update checks and online integrations degrade silently/clearly without blocking.

# Repair

Installer/app can verify required bundled components; missing/corrupt deployment gives actionable repair path.

# Tests

Clean install, upgrade, downgrade/rollback constraints, offline first launch, file association, parallel versions and corrupted update package.
