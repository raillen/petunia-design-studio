# 18.10 — Fill / Gradient Tool

# Identity

ToolId ptnd.tool.fill_gradient.

# Target

Active Appearance Fill entry. If no fill exists, behavior to create default fill is explicit and undoable.

# Modes

Linear, Radial, Conical, and Image/Pattern transform when fill type supports.

# States

Idle -> HoverHandle/Stop -> DragGeometry | DragStop | AddStop -> Commit/Cancel.

# Stop model

Stable StopId, position, color/SwatchRef, opacity, midpoint/interpolation. Position reordering does not change identity.

# Gesture

Drag establishes geometry. Click line adds stop. Drag handle edits geometry. Delete removes selected stop subject minimum count.

# Modifiers

Shift constrains angle; Alt/Option controls symmetric/focus behavior by gradient type.

# Context

Fill-entry selector, type, spread, reverse, interpolation, stop position/opacity.

# Commands

SetFillType, SetGradientGeometry, AddGradientStop, MoveGradientStop, SetGradientStop, RemoveGradientStop.

# Accessibility

Stops editable as ordered list and numeric fields; keyboard cycles handles.

# Tests

Multiple fills, transformed objects, swatch-linked stops, stop crossing, multi-select, export, undo.
