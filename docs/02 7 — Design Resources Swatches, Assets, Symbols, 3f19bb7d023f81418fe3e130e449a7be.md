# 02.7 — Design Resources: Swatches, Assets, Symbols, Styles, Brushes & Reusable Libraries

# Resource tiers

Document resources, user/application libraries and plugin/external libraries.

# Swatches

Process, global, spot and gradients. Global swatch updates references. Import/export palettes via adapters.

# Assets

Reusable object groups/components with thumbnail, tags/categories and drag/place.

# Symbols

Definitions can live document/library; placing external symbol copies/links according library policy.

# Styles

Text/object style libraries; version/import conflict policy.

# Vector brushes

Preset resources reference brush definition/texture and appear in shared Brushes system with capability type.

# Search

All large libraries support search/tags/favorites and model virtualization.

# Portability

PTND can embed required resources or reference external libraries with explicit missing-state handling.
