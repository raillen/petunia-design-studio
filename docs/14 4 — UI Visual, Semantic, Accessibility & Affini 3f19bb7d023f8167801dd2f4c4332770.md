# 14.4 — UI Visual, Semantic, Accessibility & Affinity Workflow Evidence

# Semantic tests

Inspect ToolId, ActionId, PanelId, roles, accessible names, enabled state, focus, selection and visible context controls after scripted interactions.

# Visual tests

Deterministic document + workspace + theme + DPI. Capture full shell and focused regions. Per-platform goldens where font/window differences are legitimate.

# Tool workflows

For each Design/Photo tool: activate -> operate -> modify context parameter -> undo/redo -> save/reopen -> compare canonical state and visible feedback.

# Accessibility

Keyboard-only completion of representative jobs; screen-reader inspection; focus traps; high contrast; large UI scaling; reduced motion; alternative locale.

# Affinity comparison

Human-factors comparison evaluates task steps/discoverability/feedback, not pixel similarity. Findings can justify Petunia divergence.

# Manual exploratory

Retained checklist for pen tablet, multi-monitor mixed DPI, long drag, file dialogs, IME and platform integrations hard to fully automate.
