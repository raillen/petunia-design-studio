# 24 — Import/Export Capability Matrices & Interchange Fidelity

# Purpose

Replace vague “format support” with feature-by-feature directional capability matrices.

# Dimensions

Import, Place, Export, Roundtrip; geometry, text, styles, effects, raster, masks, color spaces, ICC, spots, pages/Surfaces, resources, metadata and editability.

# Fidelity

Exact, EquivalentAppearance, Approximate, DestructiveDegradation, Unsupported.

# Rule

Marketing/release docs cannot claim a format without linking its matrix and tested version/profile.
