# 28 — Advanced Features, Deferred Scope, Research Backlog & Affinity-Class Roadmap

# Purpose

Keep advanced capability visible without making V1 unbounded.

# Status classes

V1 Required, V1 Stretch, Post-V1 Planned, Research, Plugin Territory, Not Planned.

# Photo advanced candidates

RAW development, lens correction profiles, liquify, frequency-separation helpers, panorama, HDR merge/tone mapping, focus stacking, astrophotography stacking, advanced denoise, ML selection and generative/inpainting providers.

# Design advanced candidates

Mesh gradients, advanced vector warp/envelope, pattern generators, perspective drawing expansion, advanced brushes, CAD interchange and variable-data automation expansion.

# Layout/prepress advanced

Master/template sophistication, tables, footnotes/endnotes, long-document features, advanced index/TOC, data-driven pagination, PDF/X variants, trapping.

# Collaboration/cloud

Real-time collaboration, cloud library sync and account services are not V1 architectural requirements. If introduced, remain adapters/services around local-first document model.

# AI

Generative capabilities are optional providers/plugins with explicit privacy/network permissions. Core editor remains fully useful without AI.

# Evaluation

Promotion into V1/Post-V1 requires user/workflow evidence, architecture impact, performance/security/licensing analysis and updated acceptance tests.

# Non-goal rule

Absence from V1 is deliberate when status recorded here; agents must not opportunistically implement research items during unrelated Goals.
