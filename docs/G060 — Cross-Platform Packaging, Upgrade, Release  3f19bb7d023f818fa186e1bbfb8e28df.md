# G060 — Cross-Platform Packaging, Upgrade, Release Candidate & Commercial V1 Verification

# Goal

Produce commercially installable V1 candidate on supported OSes.

# Depends

G059, release/packaging docs.

# Primary

release-verifier + devops engineer.

# Deliverables

Windows/macOS/Linux packages per final support matrix; signing/notarization; SBOM/licenses; clean install/upgrade/uninstall; PTND associations; updater channel; diagnostics/support bundle; release notes/compat statement.

# Acceptance

Fresh machines install and execute all commercial demo workflows; upgrade preserves settings/docs; artifacts signed/checksummed and rollback policy proven.

# Verdict

Release Verifier issues Go/No-Go with blockers/waivers; publication remains separate authorized action.
