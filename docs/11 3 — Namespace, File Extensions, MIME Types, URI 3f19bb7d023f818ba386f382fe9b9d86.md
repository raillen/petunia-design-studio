# 11.3 — Namespace, File Extensions, MIME Types, URIs & External Identifiers

# Native

Extension .PTND. formatId ptnd.document. Final MIME type/media registration strategy defined before public format freeze.

# Namespaces

Built-in semantic IDs begin ptnd. Third-party plugin IDs use reverse-domain or approved globally unique namespace and cannot register under ptnd.*.

# URI

Future internal help/resource/object URIs require versioned scheme; do not expose raw local file paths as durable resource ID.

# File names

Recovery/temp/library packages use distinct suffixes/directories and never masquerade as canonical PTND final save.

# Clipboard MIME

Petunia internal clipboard/drag MIME is versioned and namespaced; standard SVG/PDF/image/text formats accompany it for interoperability.

# Protocol

MCP/plugin protocol method names and IDs align vocabulary but remain separately versioned.
