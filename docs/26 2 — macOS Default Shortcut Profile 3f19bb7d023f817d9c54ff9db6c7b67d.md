# 26.2 — macOS Default Shortcut Profile

# Mapping

Use Command for application/document editing equivalents, Option for alternate geometry/tool semantics and Control only when platform convention or tool grammar requires.

# File/Edit

Cmd+N/O/S/Shift+S/W; Cmd+Z undo; Cmd+Shift+Z redo; Cmd+X/C/V; Cmd+A select all in active semantic context.

# Tools

Letter tool shortcuts generally match cross-platform profile: V, A, P, B, E, G, T, I, H, Z, with Persona/context resolution.

# Navigation

Space temporary Hand; Cmd+0 Fit; Cmd+1 100%; +/− zoom. Trackpad pinch/pan are first-class.

# Modifier semantics

Option replaces Alt in duplicate/center/source-sample behavior. Cmd-based deep selection must not conflict with macOS menu shortcuts; exact tool modifiers recorded per ToolSpec.

# Menu

macOS global menu locations follow conventions while ActionId remains identical.

# Accessibility

VoiceOver/focus navigation and system reserved shortcuts are tested; Petunia does not steal reserved combinations by default.
