# 15.8 — Migration Parity Scoreboard, Exit Evidence & Residual-Risk Ledger

# Scoreboard

Rows by capability/subsystem: Legacy present, New Spec L3, Implemented, Verified, Performance Proven, Platform Proven, Legacy Removed.

# Categories

Document/History, UI shell, Design tools, Photo tools, text, color, renderer, PTND, import/export, plugins, MCP, accessibility, release/package.

# Exit

No V1 critical row may be Gap. Deferred feature must have explicit status/ADR. Legacy dependency search gate clean except history/migration allowlist.

# Risk ledger

Known behavior differences, unsupported old plugin/runtime behavior, format migration caveats, performance regressions and temporary platform limitations with owner/milestone.

# Evidence links

Each Verified/Proven status points to immutable build/commit and evidence bundle, not free-text assertion.

# Final sign-off

Architect + quality + release verifier, with security/performance/accessibility reviewers for relevant unresolved risks.
