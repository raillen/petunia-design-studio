# 21.09 — Gaussian Blur

# ID

ptnd.effect.gaussian_blur.

# Parameters

radius/sigma relation explicitly defined; edgeMode; quality. UI may expose radius while kernel uses sigma = documented mapping.

# ROI

Expand output ROI by ceil(K*sigma) where K chosen for kernel truncation error bound, typically 3–4 sigma and fixed by implementation spec.

# Algorithm

CPU reference separable Gaussian convolution. Large radius may use multi-pass/box/IIR approximation only in interactive tier; ExportFinal must meet oracle tolerance.

# Alpha

Blur premultiplied color and alpha coherently to avoid dark fringes. Edge mode default Transparent or Clamp explicitly chosen per live-filter semantics.

# GPU

Compute/render separable pass candidate with tile halo and transient targets.

# UI

Radius numeric/slider; edge mode advanced; split preview optional.

# Tests

Impulse kernel, constant image invariance, alpha edge, tile seams, huge radius, CPU/GPU and preview/final.
