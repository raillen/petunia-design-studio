# 19.15 — Navigator Panel

# Identity

PanelId ptnd.panel.navigator.

# View

Derived thumbnail of active Surface/all Surfaces, viewport rectangle and zoom controls.

# Interaction

Drag viewport rectangle to pan; click thumbnail recenters; zoom field/slider calls ViewportController.

# Multi-Surface

Toggle active Surface vs overall document overview.

# Rendering

Low-priority offscreen thumbnail cache; stale revisions coalesced/cancelled.

# State

Pure view state, no document history.

# Accessibility

Numeric zoom/pan actions; description includes Surface and viewport bounds.

# Tests

Huge document, multi-Surface, stale thumbnail, zoom sync and mixed DPI.
