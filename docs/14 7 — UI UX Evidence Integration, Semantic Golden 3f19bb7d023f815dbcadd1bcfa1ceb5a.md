# 14.7 — UI/UX Evidence Integration, Semantic Goldens & Affinity Workflow Comparisons

# Integration

UI evidence is attached to functional requirements, not a separate design gallery. Tool/panel milestone includes semantic and visual evidence linked to fixture/build.

# Semantic goldens

Snapshot ActionId/ToolId/PanelId, control roles/names/states, focus, context controls, selection and resulting document revision/Command.

# Workflow comparison

Run same professional task in Petunia and current Affinity reference where licensing/access permits observation. Record steps, discoverability, feedback and outcome fidelity—not pixel similarity.

# Regression triage

Semantic mismatch = correctness/interaction bug. Pixel-only mismatch = visual review. Accessibility mismatch = release blocker according severity even if screenshots match.

# Evidence retention

Store normalized screenshots/video pointers plus machine-readable manifest with OS/DPI/theme/build/fixture and test command.
