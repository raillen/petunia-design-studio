# 26.1 — Windows/Linux Default Shortcut Profile

# File

New Ctrl+N; Open Ctrl+O; Save Ctrl+S; Save As Ctrl+Shift+S; Close Ctrl+W; Export Ctrl+Alt+Shift+S candidate subject conflict review.

# Edit

Undo Ctrl+Z; Redo Ctrl+Shift+Z with optional Ctrl+Y alias; Cut/Copy/Paste Ctrl+X/C/V; Duplicate Ctrl+J candidate; Delete Delete/Backspace context-aware.

# Selection

Select All Ctrl+A when not text-editing; Deselect Ctrl+Shift+A; Group Ctrl+G; Ungroup Ctrl+Shift+G; Lock/Unlock assigned only after conflict audit.

# Tools

V Move; A Node; P Pen; N Pencil candidate; B Pixel Brush in Photo / Vector Brush profile conflict solved by Persona context; E Eraser; G Fill/Gradient; T Text group; C Crop candidate; I Eyedropper; H Hand persistent; Z Zoom.

# Navigation

Space temporary Hand; Ctrl+0 Fit; Ctrl+1 100%; +/− zoom; Tab Focus Canvas/chrome toggle only if not captured by text focus.

# Panels

Shortcut scheme for Layers/Properties/Color/History uses configurable function-key or Ctrl+Alt combinations after OS conflict test; Command Palette Ctrl+Shift+P candidate.

# Text context

Standard Ctrl+B/I only if semantic typography shortcut chosen and does not conflict; Ctrl+A/C/V/Z follow text editor when caret active.

# Rule

This is initial profile, finalized through conflict/user-testing ledger before V1. ActionIds own semantics; labels/keys can evolve by profile version.
