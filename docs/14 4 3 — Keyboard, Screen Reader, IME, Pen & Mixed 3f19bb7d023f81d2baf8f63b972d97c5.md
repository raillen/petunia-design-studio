# 14.4.3 — Keyboard, Screen Reader, IME, Pen & Mixed-DPI Manual/Automated Matrix

# Keyboard

Automated semantic scripts cover menu/palette/tool activation, panel focus, Layers navigation, Properties edit, text editing, save/export and recovery.

# Screen reader

Manual/repeatable matrix per platform: NVDA/JAWS Windows, VoiceOver macOS, Orca Linux as available. Record versions and unsupported Qt/platform limitations.

# IME

CJK composition, candidate placement, cancellation/commit, caret movement around composition, shortcut isolation and text undo.

# Pen

Pressure/tilt/eraser/buttons, hover, proximity loss, pointer capture and high-frequency stroke. Representative hardware/device profile recorded.

# DPI

Window moves between 100/150/200% or Retina/non-Retina displays, floating panels, canvas cursor/handles and renderer target recreation.

# Accessibility profile

High contrast, larger handles/cursors, reduced motion and comfortable density tested in critical flows.
