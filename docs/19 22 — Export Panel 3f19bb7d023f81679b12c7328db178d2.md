# 19.22 — Export Panel

# Identity

PanelId ptnd.panel.export.

# Model

ExportTarget/Slice list with name, source Surface/object/region, preset, scale variants, output name preview and status.

# Actions

Create slice from selection/Surface; rename; duplicate; delete; assign preset; add scale; reveal on canvas; Export Selected/All.

# Naming

Live preview uses sanitized output template and flags collisions before export.

# Presets

Exporter-specific presets with compatibility badge; unavailable exporter/provider retained as missing preset state.

# Jobs

Rows display queued/running/success/warning/error; link to ExportReport. Progress updates coalesced.

# Drag/reorder

Target ordering affects batch order only, not document paint.

# Accessibility

Table/list semantics and all target actions keyboard accessible.

# Tests

1000 slices, collisions, plugin exporter missing, job cancellation and workspace restore.
