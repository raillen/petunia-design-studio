# 00 — Product Charter & Scope

# Produto

Petunia Design Studio é um editor desktop profissional híbrido de **vetor + raster + layout** com um único modelo de documento e duas Personas principais: **Design** e **Photo**. O objetivo não é clonar o Affinity, e sim atingir paridade de classe de produto com uma arquitetura própria, aberta, modular e automatizável.

# Personas

## Design

Vetor, ilustração, shapes paramétricas, pen/node, strokes, fills, gradients, booleans, appearance stack, typography, artboards/Surfaces, pages, grids, guides, layout editorial selecionado, symbols, assets, styles, data merge e export preparation.

## Photo

Raster, pintura, brush engine, seleções, masks, channels, adjustments, live filters, crop, heal, clone, inpaint, dodge/burn, histogram, scopes, image transforms e compositing.

# Escopo de Layout

Layout é parte de Design: pages, master-like Surface Templates, text frames linked, columns, margins, baseline grid, bleed, text wrap, preflight e Data Merge. Não existe Publisher Persona separada.

# Público

- designers gráficos e de marca;
- ilustradores;
- fotógrafos e retouchers;
- pequenas equipes de marketing;
- criadores que desejam uma alternativa Linux/Windows/macOS profissional;
- usuários que precisam de automação, plugins e MCP sem perder interface manual.

# V1

V1 deve permitir criar, editar, salvar, reabrir e exportar projetos reais com vetor + raster misturados. O mínimo comercial inclui:

- seleção/transform;
- pen/node/pencil;
- shapes e booleans;
- fills/strokes/gradients;
- layers/groups/clips/masks;
- text artistic/frame/path;
- artboards/Surfaces;
- raster layers;
- brush/eraser;
- selections/masks;
- core adjustments/live filters;
- color management ICC;
- .PTND robusto;
- SVG/PDF/PNG/JPEG/TIFF/WebP export;
- docking, workspaces, shortcuts, accessibility;
- plugin API e MCP semantic baseline.

# Não objetivos V1

- competir integralmente com Photoshop/Affinity em cada filtro legado;
- DTP de centenas de páginas com todos os recursos de InDesign;
- vídeo/motion;
- 3D;
- cloud collaboration como requisito central;
- IA generativa como dependência do fluxo principal.

# Qualidade de produto

A UI precisa ser silenciosa, densa sem ser claustrofóbica, keyboard-first quando desejado, totalmente operável por pointer/pen, e manter 60–120 Hz de feedback interativo nas operações de canvas em hardware-alvo definido.
