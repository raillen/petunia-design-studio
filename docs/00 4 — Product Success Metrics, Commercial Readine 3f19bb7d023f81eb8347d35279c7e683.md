# 00.4 — Product Success Metrics, Commercial Readiness & Quality Bar

# Success dimensions

Correctness/data safety; workflow completeness; performance; interoperability; accessibility; stability; maintainability; extension safety.

# Commercial readiness gates

No known reproducible P0 data-loss/corruption; recovery tested.

Core workflows finish without dev console/manual file edits.

Install/update/uninstall work on supported OS.

Accessibility critical paths verified.

Performance Tier L/R documented.

Output formats validated against external readers.

Licenses/SBOM/update signing complete.

Crash diagnostics/recovery understandable by support.

Plugin/MCP disabled-by-default authority appropriate and secure.

# Reliability targets

Crash-free session target and data-loss target are measured after telemetry/test infrastructure exists; no fabricated percentage before data. Internal release uses zero known P0/P1 data integrity blockers.

# Feature readiness

Spec Complete -> Scaffolded -> Implemented -> Verified -> Release Proven. Marketing claims require Release Proven for named capability.

# UX quality

No core workflow requires hidden modifier knowledge; command palette/help can reveal alternatives. Advanced complexity remains available without overwhelming default workspace.
