# 00.5 — Golden User Workflows & Acceptance Narratives

# Workflow A — Brand/Logo

Create shapes/path, boolean, typography, global colors, align, symbol/style, multi-export SVG/PDF/PNG.

# Workflow B — Marketing Poster

Place photo, nondestructive adjustment/mask, vector layout/text/effects, export web and print variants.

# Workflow C — Photo Retouch

Crop, selections/refine, heal/clone, curves/HSL, dodge/burn, mask, color-managed TIFF/JPEG.

# Workflow D — Light Publishing

Multi-page Surfaces, linked text frames, paragraph styles, margins/columns/bleed, images, preflight, PDF.

# Workflow E — Data Merge

CSV/JSON source, bindings, record preview, preflight, batch asset generation.

# Workflow F — Automation

MCP or plugin inspects document, performs semantic edits, exports and produces same result as GUI workflow.

# Acceptance

Each workflow has fixture, scripted steps, expected semantic snapshot, output artifacts, accessibility path and performance observations.
