# 11.4 — Brand/UI Identity Separation from Affinity & Reference Products

# Principle

Affinity is functional prior art, not a visual asset source.

# Petunia-owned

Palette, logo, flower/brand motifs, icon library, typography choices, selection colors, spacing/density tokens and component states.

# Convention vs copying

Left tool rail/right panels/context toolbar are common editor conventions; exact icons, proprietary symbols, arrangement details and branded terminology must be independently designed.

# Reference documentation

When recording Affinity behavior, include observed workflow/capability and Petunia rationale, not screenshots copied into production assets.

# Audit

Visual-identity-auditor can compare product against references and flag trade-dress drift.
