# 30 — Action, Property, Capability & Semantic ID Registry Catalog

# Purpose

Make stable IDs a first-class product contract.

# Registries

ActionId, ToolId, PanelId, PropertyId, EffectId, AdjustmentId, ObjectTypeId, FormatId, CapabilityId, HelpId, TextId and ErrorCode namespace rules.

# Catalog fields

ID, owner module, since version, status/deprecation, human label TextId, parameter/value schema, permissions, availability/context, side effects, undo/revision, plugin/MCP visibility and tests.

# Rule

IDs are never generated from localized labels/class names. Renames preserve ID unless semantics truly change.
