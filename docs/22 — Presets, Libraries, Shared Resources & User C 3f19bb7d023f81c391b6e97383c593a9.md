# 22 — Presets, Libraries, Shared Resources & User Content

# Purpose

Unificar brushes, swatches, gradients, styles, assets, export presets, workspaces, shortcut profiles and reusable user resources under uma arquitetura coerente.

# Resource scopes

BuiltIn, ApplicationUser, Document, Workspace/Profile, PluginProvided, ExternalLinked.

# Requirements

Stable IDs, versioned schemas, import/export, conflicts, provenance/license metadata where needed, search/tags/favorites, backup/restore, plugin contribution, missing-provider behavior and migrations.
