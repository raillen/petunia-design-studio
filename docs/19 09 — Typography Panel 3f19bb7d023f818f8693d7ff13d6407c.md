# 19.09 — Typography Panel

# Identity

PanelId ptnd.panel.typography.

# Target

Active caret/range or selected TextObject(s). Computed values can be Mixed.

# Font

Family search, style, favorites/recent, missing state, variable axes and size.

# Character controls

Tracking, kerning, baseline shift, scaling if supported, language, underline/strikethrough, text color.

# OpenType

Ligatures, alternates, small caps, numeral styles, fractions, stylistic sets and arbitrary supported tags in advanced section.

# Variable fonts

Dynamic fields from font metadata, named instances, reset. Axis edits re-shape/reflow under one transaction.

# Commands

SetCharacterStyleProperties, ApplyCharacterStyle, SetFontVariation.

# Accessibility

Font preview is not sole identifier; controls named/stated.

# Tests

Variable fonts, missing font, mixed ranges, bidi, OpenType, undo and save.
