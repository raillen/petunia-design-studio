# 19.05 — Swatches Panel

# Identity

PanelId ptnd.panel.swatches.

# Collections

Document palette, Application/User palettes, plugin/external libraries. Palette selector and search.

# Swatch types

Process color, Global color, Spot color, Registration, Gradient/Pattern if allowed. Type visibly badged.

# Interaction

Click applies to active Fill/Stroke/ColorTarget; modifier can switch target. Double-click edits owned/document swatch; read-only library opens details/copy.

# Management

Create, duplicate, rename, group, reorder, delete, convert global/spot/process, import/export palette. Deleting referenced global/spot requires replace/detach policy.

# Search/tags

Large libraries virtualized and filterable. Favorites/user recents optional.

# Drag/drop

Drag swatch onto eligible object/appearance target generates semantic set action; not raw color MIME only.

# Accessibility

Swatch exposes name, type and numeric alternate color.

# Tests

Global propagation, spot rename, deletion refs, library missing, palette import and drag application.
