# 02.5 — Typography & Layout: Artistic Text, Frames, Linked Stories, Surfaces & Publishing Features

# Text types

Artistic text for labels/headlines; Frame text for paragraphs/layout; Text-on-path for decorative/path typography.

# Story flow

Frames can link in sequence. Overset state visible. Columns, insets, alignment, hyphenation and paragraph styles.

# Surfaces

Artboards/pages share Surface abstraction. Sequential page order supported without preventing arbitrary spatial artboards.

# Publishing

Margins, bleed, columns, baseline grid, page numbering fields and reusable Surface Templates.

# Text wrap

Objects can provide text-wrap contour/offset where implemented. Wrap is live derived layout and serialized semantic property.

# Preflight

Overset text, missing fonts, missing resources, unsupported color/export capabilities and bleed issues.

# Data Merge

Layout objects can bind fields/images/properties and preview records nondestructively.

# Scope

This achieves lightweight/professional publishing without splitting a third Persona.
