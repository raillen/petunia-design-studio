# 19.10 — Paragraph Panel

# Identity

PanelId ptnd.panel.paragraph.

# Controls

Alignment/justification, leading policy, spacing before/after, left/right/first-line indents, tabs, hyphenation/language, keep options, widow/orphan, baseline-grid alignment.

# Justification advanced

Min/desired/max word spacing, letter spacing and glyph scaling only when engine supports them.

# Tabs

Visual ruler + table: position, left/right/center/decimal, leader. Numeric/keyboard alternative.

# Mixed paragraphs

Cross-paragraph selection shows Mixed and applies semantic range updates.

# Commands

SetParagraphProperties, ApplyParagraphStyle, SetTabStops.

# Accessibility

Alignment icons named; tab ruler has list alternative.

# Tests

Multilingual paragraphs, mixed selection, tabs/decimal locale, linked frames, baseline grid and undo.
