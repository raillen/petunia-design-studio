# 25.5 — AI/EPS/IDML/DXF-DWG & Other Interchange Roadmap

# Illustrator AI

PDF-compatible AI files may be readable through PDF content where legitimate. Proprietary Illustrator edit data is not assumed. Claim must say “PDF-compatible AI import” if that is what exists.

# EPS

Legacy vector/print interchange candidate. No transparency/layers in many workflows; import/export fidelity matrix required. PostScript execution/parser security is high risk.

# IDML

Post-V1 publishing interchange candidate. Maps pages, frames, text styles, placed resources and colors where possible. Complex master/layout semantics require dedicated importer, not generic XML flatten.

# DXF/DWG

Post-V1 CAD/vector interchange. Units, layers, lines/arcs/splines/text, coordinate precision and model/paper space need dedicated semantics. DWG library licensing is gating factor.

# Other

PDF/SVG/raster remain first priority. New formats enter only via market need + license/security/fidelity evidence.

# Rule

Adapter roadmap cannot influence canonical document into lowest-common-denominator representation.
