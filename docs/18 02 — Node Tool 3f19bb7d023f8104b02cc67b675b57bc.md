# 18.02 — Node Tool

# Identity

ToolId ptnd.tool.node. Shortcut A.

# Eligible targets

VectorPath and editable path results. Parametric shapes use their own semantic handles until Convert to Curves.

# States

Idle -> HoverNode/Segment/Handle -> Select/Marquee -> DragNodes | DragHandle | SegmentAdjust -> Commit/Cancel.

# Selection

Click node; Shift toggle; marquee nodes. Sub-selection uses stable NodeId.

# Editing

Move nodes with snapping; drag handles; Cusp/Smooth/Symmetric coupling. Double-click segment inserts node preserving curve.

# Context

node type; join/break; close/open; reverse; delete; delete-preserve-shape; line/cubic; snapping; selected-node transform.

# Commands

EditPathNodes, InsertNode, DeleteNodes, SetNodeType, JoinEndpoints, BreakPath, ClosePath, ReversePath.

# Native engine

Nearest point, exact insertion, topology and snapping live in GeometryEngine.

# Accessibility

Coordinates/node type editable through Properties; keyboard nudge and node cycling; semantic canvas labels.

# Tests

Insert preserves curve, reverse twice identity, closed contour endpoints, overlapping nodes, Live Boolean operand isolation, undo.
