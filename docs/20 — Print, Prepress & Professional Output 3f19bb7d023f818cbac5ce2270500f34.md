# 20 — Print, Prepress & Professional Output

# Scope

Consolidar capacidades profissionais de impressão que não devem permanecer dispersas entre Color e Export: separations, overprint, spots, ink coverage, boxes/marks, PDF/X, font/output checks and print preflight.

# Principle

Petunia só declara suporte profissional quando a semântica é preservada e verificável por validator/reference output. Preview visual não substitui conformance.
