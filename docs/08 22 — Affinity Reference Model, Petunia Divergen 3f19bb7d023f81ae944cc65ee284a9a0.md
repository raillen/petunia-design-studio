# 08.22 — Affinity Reference Model, Petunia Divergence Rules & Workflow Vocabulary

# Current reference

Treat current unified Affinity as a workflow corpus across Vector, Pixel and Layout Studios, panels, context controls, slices, print/preflight and scripting.

# Mapping vocabulary

Affinity Studio/workspace concept -> Petunia Persona + Workspace.

Affinity vector tools -> Petunia Design tools.

Affinity pixel/photo tools -> Petunia Photo tools.

Affinity Layout capabilities -> Petunia Design layout subsystem.

Affinity export/slices -> Petunia Export panel/targets.

# Divergence rules

Diverge when Petunia architecture can reduce mode confusion, improve accessibility, enable Linux, improve automation semantics or avoid destructive behavior.

# Copy prohibition

Do not copy proprietary icons, exact branded color system, marketing terminology unique to Affinity, screenshots/assets or pixel-for-pixel chrome.

# Evidence

Reference claims should record source/date/version because Affinity evolves. Coverage ledger tracks capability, observed interaction, Petunia decision and authority page.
