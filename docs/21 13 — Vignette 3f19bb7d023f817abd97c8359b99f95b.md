# 21.13 — Vignette

# ID

ptnd.effect.vignette.

# Parameters

amount/exposure, midpoint/radius, roundness/aspect, feather/softness, center offset, color/tint optional.

# Geometry

Effect computes normalized elliptical distance in chosen object/Surface coordinates. On-canvas center/radius handles optional.

# Color

Darken/lighten function defined in working lightness/exposure representation; tint application explicit.

# ROI

Point effect within object/output bounds, no source halo.

# UI

Sliders and canvas handles; reset center.

# Tests

Square/wide images, center shift, roundness, positive/negative amount, alpha and transform.
