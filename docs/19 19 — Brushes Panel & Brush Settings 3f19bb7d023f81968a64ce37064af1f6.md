# 19.19 — Brushes Panel & Brush Settings

# Identity

PanelIds ptnd.panel.brushes and ptnd.panel.brush_settings.

# Brushes browser

Virtualized preset grid/list; categories/tags/search/favorites/recent/provider. Thumbnail/stroke preview derived from preset.

# Apply

Selecting preset updates active brush tool settings, not existing painted content. If no brush-like tool active, selection can be remembered until activation.

# Management

New from current settings, duplicate, rename, tag/category, delete user preset, import/export pack, reset built-in. Built-ins read-only.

# Brush Settings

Sections Tip, Size, Spacing, Shape, Texture, Scatter, Dynamics, Rotation, Opacity/Flow, Stabilizer, Operator-specific. Each parameter has typed schema.

# Dynamics curves

Graph editors with input axis and output mapping, numeric table/accessibility alternative.

# Modified state

Preset name shows “modified”; Save New/Update only when ownership permits.

# Tests

Thousands of presets, provider missing, modified state, dynamics serialization, import pack and tool synchronization.
