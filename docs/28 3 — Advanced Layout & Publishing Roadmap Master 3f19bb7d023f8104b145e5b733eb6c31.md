# 28.3 — Advanced Layout & Publishing Roadmap: Masters, Tables, TOC, Footnotes & Long Documents

# Surface Templates/Masters

V1 has lightweight templates; advanced roadmap may add hierarchical masters, per-page overrides and spread-aware objects.

# Tables

Structured table object with rows/columns/cells, spans, text stories, border/fill styles, resizing and Data Merge compatibility.

# TOC/Index

Generated semantic fields from paragraph/text styles, page ordering and index markers. Generation is deterministic and refreshable, not pasted text.

# Footnotes/endnotes

Story-level anchored note model, numbering and frame/page flow rules. Requires deep text-layout support.

# Long document

Sections, page numbering styles, linked documents/book concept, resource/style synchronization and large-story performance.

# Advanced text

Optical margin alignment, baseline/vertical-grid sophistication, GREP-like styles, keep rules, drop caps and advanced justification as separate milestones.

# Status

Post-V1 unless commercial requirements promote them; lightweight brochure/publishing remains V1 Design scope.
