# 14.4.4 — Professional Workflow Comparison Protocol vs Affinity/Krita/Adobe Prior Art

# Goal

Use reference applications to evaluate workflow expectations without pixel cloning or assuming reference behavior is correct.

# Tasks

Logo/vector icon; poster; brochure/page layout; photo retouch; cutout/mask; batch/social export; spot/print preflight; Data Merge when comparable.

# Measures

Number/clarity of steps, discoverability, precision access, state visibility, accidental destructive conversion, recovery/undo confidence, keyboard reach, performance perception and result fidelity.

# Observation

Record app/version/platform/date. Separate observed fact from interpretation/recommendation.

# Petunia divergence

A divergence is acceptable/preferred when it reduces mode confusion, improves accessibility, exposes live/destructive state, strengthens automation or simplifies common workflow without lost power.

# No copying

No reuse/tracing of proprietary assets/icons; screenshots used internally as research evidence subject to rights/policy and not shipped.

# Outcome

Findings update Tool/Panel/Product authority through reviewed requirement/ADR, not informal imitation.
