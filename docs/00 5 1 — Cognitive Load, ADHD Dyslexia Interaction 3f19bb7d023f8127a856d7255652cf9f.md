# 00.5.1 — Cognitive Load, ADHD/Dyslexia Interaction Principles & Focus Modes

# Principles

Reduce working-memory burden, preserve spatial consistency, expose state, make recovery cheap and support interruption/resumption.

# Stable placement

Common controls keep stable relative position by tool family. Panels do not reorder themselves based on transient selection without user choice.

# Progressive disclosure

Context bar contains frequent controls; Properties contains full set; rare expert options sit in explicit advanced sections. Hiding complexity must not hide state.

# Focused workspaces

Minimal Canvas and task-specific workspace presets reduce visible panels while Command Palette/Search retains all capabilities.

# Interruption recovery

Active tool/target/selection and unfinished staged operation are obvious. Long jobs survive focus changes and report meaningful completion/errors.

# Dyslexia/readability

Avoid all-caps long labels, tiny condensed text and ambiguous icon-only sequences. Support comfortable density, tooltip verbosity and high-clarity numeric fields.

# ADHD attention

Avoid decorative motion, badge noise and repetitive success toasts. Group background notifications and prioritize actionable errors.

# Testing

Task-based studies include interruption scenarios, panel-search recovery, multi-step workflows and subjective cognitive load—not diagnosis-based assumptions.
