# 00.5 — Accessibility & Neurodivergent-Friendly Product Contract

# Cognitive stability

Controls for same concept stay in consistent location/family. Persona changes relevant tools/panels but does not arbitrarily rearrange unrelated chrome.

# Focus modes

Minimal Canvas and Focused workspace profiles reduce visible complexity without removing capabilities. User can restore panels via search/command palette.

# Search first

Actions, settings, panels, tools, assets and help searchable. Search results expose category/shortcut and execute same semantic IDs.

# Readability

Comfortable density, larger handle/cursor mode, high contrast, reduced motion, adjustable tooltip detail and predictable typography.

# Error messaging

One clear cause and recovery action, with technical detail collapsible. Avoid multiple simultaneous transient toasts for same root issue.

# Attention

Background jobs are quiet unless completion/error matters. Animation used for feedback, not decoration. Status changes do not steal keyboard focus.

# Keyboard

Remappable profiles and discoverable shortcuts; no chord required for an action that cannot also be reached by menu/palette.

# Screen readers

Semantic canvas summary, full panels/controls, selection/tool/target announcements with verbosity settings.

# Testing

Representative ADHD/dyslexia/cognitive-load review included in UX studies alongside WCAG mechanics.
