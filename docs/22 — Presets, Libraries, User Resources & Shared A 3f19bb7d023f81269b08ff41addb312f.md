# 22 — Presets, Libraries, User Resources & Shared Asset Architecture

# Goal

Unify brushes, swatches, gradients, styles, assets, workspaces, shortcuts and export presets under coherent resource-library semantics.

# Resource scopes

BuiltIn, ApplicationUser, Document, ExternalLibrary, PluginProvided, Team/Shared future.

# Common requirements

Stable IDs, versioned schema, provenance, search/tags, favorites, import/export, conflict resolution, missing provider handling, backup/restore, migration and permission boundaries.

# Rule

A preset is declarative data where possible, not arbitrary executable code.
