# 08.17 — Affinity 2026 Reference Model, Petunia Divergence & Workflow Vocabulary

# Reference

Affinity é prior art de workflow. Petunia captura ergonomia/completude, não aparência proprietária.

# Adopt conceptually

- unified vector/pixel/layout document;
- customizable Studios/workspaces;
- tool rail + context-sensitive controls;
- dense dock panels;
- non-destructive layers/effects;
- slices/export presets;
- professional color/preflight;
- scripting/automation.

# Petunia divergences

- Design + Photo Personas; layout em Design;
- open .PTND;
- explicit Actions/Commands for UI/plugin/MCP;
- out-of-process untrusted Python plugins;
- semantic inspection API;
- Linux first-class;
- core/UI separation;
- offline/local professional workflow sem cloud requirement.

# Visual divergence

Own palette, icons, spacing, selection, typography and brand.
