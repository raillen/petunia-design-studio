# 00.3 — V1 / Stretch / Post-V1 / Not-Planned Capability Matrix

# V1 Required

Canonical PTND; Design+Photo; vector shapes/paths; selection/transform/snapping; fills/strokes/gradients; layers/groups/clips/masks; text artistic/frame/path; Surfaces/layout basics; tiled raster/brush/eraser; pixel selection/refine baseline; crop; clone/heal/inpaint baseline; core adjustments/live filters; ICC/color baseline; PNG/JPEG/WebP/TIFF/SVG/PDF; docking/workspaces; plugins/MCP baseline; recovery/accessibility.

# V1 Stretch

Shape Builder advanced polish; variable-width advanced editor; perspective grid; basic warp; richer print PDF/X target; Data Merge full generation; asset/symbol library breadth.

# Post-V1 Candidate

RAW develop, liquify, panorama, HDR merge/tone map, focus stacking, mesh gradients, deeper DTP master/page systems, advanced denoise, tracing/vectorization, external linked PTND, WASM plugin tier, PSD/IDML/DWG deep interchange, collaboration/cloud providers.

# Research

Generative/inpainting providers; ML selection; HDR/wide-gamut display; advanced GPU compute architecture; professional trapping/imposition.

# Not planned by default

Video timeline/motion graphics, full 3D/DCC, DAW, cloud-account requirement, browser-first editor, proprietary undocumented file-format cloning as core strategy.

# Rule

Moving capability between classes updates product charter, architecture impact and implementation ledger with rationale.
