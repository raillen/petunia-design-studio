# 11.3 — File Extensions, MIME Types, Clipboard/MIME & Protocol Names

# Native

Extension .PTND canonical. MIME type finalized before public registration; internal provisional type cannot change silently after ecosystem adoption.

# Companion types

PTND recovery/temp/cache files use internal extensions not presented as user document and are never registered as primary file association.

# Clipboard

Vendor MIME e.g. application/x-petunia-selection+zip/json versioned, plus SVG, PDF/image/plain text standard representations. Exact registered string documented in schema.

# IPC/protocol

Plugin RPC and MCP protocol versions have names separate from app version. Shared-memory descriptors and URI schemes, if any, registered centrally.

# File detection

Extension is hint; content signature/manifest is authority.

# Security

Unknown extension never causes arbitrary parser selection without sniff limits.
