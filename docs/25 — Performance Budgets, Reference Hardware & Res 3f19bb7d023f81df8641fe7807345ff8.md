# 25 — Performance Budgets, Reference Hardware & Responsiveness SLOs

# Purpose

Turn performance methodology into numeric budgets tied to reference hardware and fixtures.

# Metrics

startup, new/open/save, frame p50/p99, pointer-to-preview, brush backlog, hit-test, snapping, text layout, Layers virtualization, export throughput, RAM/VRAM, autosave stalls and long-session growth.

# Policy

Budgets start provisional, then become locked after first representative implementation measurement. Regression thresholds are explicit and evidence-backed.
