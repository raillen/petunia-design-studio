# 19.14 — History Panel

# Identity

PanelId ptnd.panel.history.

# Model

Chronological HistoryEntry list + current pointer + savepoint marker. Labels derive Action metadata.

# Navigation

Selecting earlier/later entry invokes Undo/Redo to that point, not arbitrary snapshot replacement.

# Rows

Action icon, localized label, optional target summary, savepoint. Source badge plugin/MCP available in developer/audit mode.

# Branch

V1 linear. New mutation after undo truncates redo.

# Memory

Advanced diagnostics may show entry size/history budget, hidden in normal workflow.

# Keyboard

Arrow list navigation; Enter moves history pointer; global Undo/Redo unchanged.

# Accessibility

Current position and next undo/redo action announced.

# Tests

Coalesced typing, brush entries, savepoint, pruning, jumps and redo invalidation.
