# 02.3 — Vector Appearance: Fill, Stroke, Gradients, Multi-Appearance, Blending & Effects

# Appearance stack

Object can carry multiple fills/strokes/effects. UI must not reduce object to one fill + one stroke.

# Fill

Solid, gradient, image/pattern. Global/document swatch references preserve linkage.

# Gradients

Linear/radial/conical baseline; mesh research/deferred. Stops have semantic IDs and color/opacity.

# Stroke

Alignment, caps, joins, dashes, arrowheads and variable width/profile.

# Transparency

Object opacity and gradient transparency/mask workflow explicit.

# Effects

Nondestructive shadows/glows/blurs/outlines and future effect nodes.

# Blend

Professional blend-mode baseline, consistent across vector/raster/group evaluation.

# Appearance panel

Ordered entries, target selection, visibility, duplicate/reorder/remove. Fill/Stroke tools operate selected entry.

# Export

Appearance fidelity analyzed per target; expansion/rasterization never hidden.
