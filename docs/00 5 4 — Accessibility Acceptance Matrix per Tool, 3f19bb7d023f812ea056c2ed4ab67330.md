# 00.5.4 — Accessibility Acceptance Matrix per Tool, Panel, Dialog & Release

# Component checklist

Accessible name/role/state/value; keyboard focus/activation; visible focus; error semantics; tooltip/help; scale; color independence; reduce motion; screen-reader update behavior.

# Tool checklist

Keyboard activation, current mode/target announcement, numeric alternative for precision, cancel path, modifier hint, semantic output and pointer-only limitation explicitly justified.

# Panel checklist

Focus entry/exit, row navigation, tree/table roles, search, context actions, drag alternative and large-data virtualization without inaccessible custom canvas rows.

# Dialog checklist

Initial focus, tab order, default/cancel, validation association, no keyboard trap and destructive outcome wording.

# Release

Critical flows: create/edit/save/export vector; photo mask/adjustment; recovery; preferences/shortcuts; plugin permissions; preflight/export.

# Evidence

Accessibility Reviewer records platform/assistive tech/version, workflow, issue severity and unresolved limitation.
