# Rule

A tool is not specified merely by naming it. Each tool/operation needs input model, selection rules, state machine, preview behavior, commit/undo semantics, snapping, modifier keys, degenerate geometry handling, numerical tolerances, error behavior, serialization impact, automation surface and tests.

# Scope

Vector editing, object structure, appearance, typography/layout, surfaces, perspective, raster selection/painting, masks, adjustments/filters, data merge and cross-Persona behavior.
