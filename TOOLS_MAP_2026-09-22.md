## Como usar este guia (fluxo batch uma-a-uma)

1. Você manda um prompt batch por ferramenta. Ex.: `Batch 1 — Select: ...`, `Batch 2 — Pen: ...`.
2. Cada batch deve dizer: comportamento esperado nas 3 referências + o que corrigir/criar aqui + restrições (sem UI global, via `Command`, com teste).
3. Eu implemento só aquela tool em `crates/petunia_design_shell/src/tools/<tool>.rs` (+ `manager.rs` se preciso, + teste em `crates/petunia_design_shell/tests/tools_test.rs`).
4. Template de batch recomendado (copie e preencha):

```text
Batch N — <Tool> (<arquivo>):
Referência: Photoshop faz X / Affinity faz Y / CorelDRAW faz Z.
Quero: gesto A, modificadores B, commit via Command C, overlay D, cancel E.
Não mexer: <fora de escopo>.
Critério de aceite: <teste + comportamento observável>.
```

> Atenção: stubs atuais são **silenciosos** (`Ok(ChangeSet::empty())`). Não há `todo!`. Só teste revela stub.
